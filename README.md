# Vado Technologies LLC website

Prepared for: `vadotechnologiesllc.com`

Contact: `domenico@vadotechnologiesllc.com`

## Publish on GitHub Pages

1. Create a new public GitHub repository, e.g. `vado-technologies-website`.
2. Upload every file in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select **main** and **/(root)**.
6. Set the custom domain to `vadotechnologiesllc.com`.
7. Keep the included `CNAME` file.
8. Once DNS is valid, enable **Enforce HTTPS**.

## Important

Do not delete the existing MX/TXT records for `vadotechnologiesllc.com` because they are used by the company email.

The website intentionally does not include a street address because no confirmed legal address was provided in the site brief.
